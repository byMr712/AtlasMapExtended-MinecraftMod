# 3D-карты в рамках — зафиксированное поведение

Этот файл фиксирует решения, которые уже несколько раз случайно ломались.
При изменениях `client/framed3d` сверяйся с ним.

## Стрелки (`arrow_*`)

Правильное поведение:

- стрелка **лежит плашмя** в плоскости карты;
- крутится **вокруг своей собственной продольной линии** (bullet spin, «как патрон»);
- направление линии берётся из суффикса иконки: `e/w/n/s/ne/nw/se/sw`;
- **противоположные направления нормализуются к одной стороне**: например,
  `arrow_e` и `arrow_w` крутятся вокруг общей восточной оси, `arrow_n` и
  `arrow_s` — вокруг общей северной. Поэтому пара противоположных стрелок
  визуально вращается одинаково;
- это **не** вращение вокруг нормали карты и **не** вертикальный юг. Такие
  варианты уже пробовали — получалось «не как патрон».

Код: `FramedMapRenderer.rotateAroundArrowAxis`.

Тайминг одинаков для всех иконок:

- `SPIN_TICKS = 80` — полный оборот примерно 4 секунды;
- `SPIN_PAUSE = 5` — пауза 0.25 секунды после каждого оборота;
- easing — smootherstep (плавный разгон и торможение, «инерция»).

Код: `FramedMapRenderer.spinAngle`.

## Обычные 3D-иконки меток

- лежат/стоят объёмно, толщина `IconVoxelShapes.DEPTH = 2`;
- масштаб `ICON_SCALE = 1.0`, низ иконки на 6 пикселей выше поверхности
  (`FramedMapMesher.ICON_HOVER = 6`);
- на горизонтальной карте (пол/потолок) стоят вертикально и крутятся вокруг
  вертикальной оси;
- на настенной карте крутятся вокруг вертикали карты.

## Свет рамок

- обычная рамка: 3D-слой и иконки освещаются реальным светом мира
  (`state.lightCoords`), в темноте темнеют;
- светящаяся рамка: полный свет + усиление (рельеф ×1.45, иконки ×1.5).

Код: `FramedMapRenderer`.

## Район и рисунки

- заливка района **впекается в цвет поверхности** рельефа (альфа `0x55`),
  а не висит отдельной плоскостью;
- контур района и линии рисунков идут по поверхности, на 1.5 пикселя выше,
  чтобы не утопать;
- никакого общего парящего оверлея поверх карты.

Код: `FramedMapMesher` (tint в `build`, `addLine`).

## Данные 3D-объёма

- сэмплируется вся площадь карты из загруженных чанков, а не только пиксели,
  исследованные ванильной картой;
- пропущенные колонки добираются в фоне (`FramedMapCache.retryMissing`);
- высота — только верхний блок (без пещер и навесов) + профиль 20 блоков
  для слоёв на срезах;
- глубина воды считается по реальному столбу воды;
- формат `.bin` версионируется; при несовпадении версии объём
  пересэмплируется.

## Палитра

- карта в руках и в рамке берёт пиксели из тайлов мода (как миникарта),
  с фолбэком на ванильные цвета;
- 3D-рельеф использует ту же `ChunkScanner.papyrus`, поэтому палитра суши,
  воды и слоёв совпадает с миникартой.
